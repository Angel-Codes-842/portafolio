# Portafolio Web — Ángel Gómez

Portafolio personal con estética retro-tech 8-bit minimalista, construido con React y Tailwind CSS. Incluye proyectos en producción, currículum descargable y datos de contacto actualizados desde el CV.

## 🚀 Demo

[Ver portafolio en vivo](https://portafolio-rkbv.onrender.com)

## 🛠️ Tecnologías

- React 18
- Tailwind CSS
- Vite
- React Icons
- Vitest + Testing Library

## 📦 Instalación

```bash
# Clonar repositorio
git clone https://github.com/Angel-Codes-842/portafolio-web.git

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build

# Ejecutar pruebas
npm test
```

## 📁 Estructura

```text
src/
├── components/
│   ├── layout/      # Navbar, Footer
│   ├── sections/    # Hero, About, Projects, Resume, Contact
│   └── ui/          # Componentes reutilizables
├── data/            # profile.js y projects.js
├── hooks/           # Custom hooks
└── index.css        # Estilos globales
public/
├── cv/              # CV en PDF
└── images/          # Foto de perfil y capturas de proyectos
```

## 💼 Proyectos incluidos

- **FactuSYS** — ERP/POS con facturación SET, stock por lotes, multisucursal y despliegue con Docker.
- **SysTurno** — Gestión de turnos en tiempo real con Django Channels, WebSockets, kiosko y pantallas TV.
- **POS Multi-Sucursal (Panadería)** — Ventas, arqueo de caja, inventario y sucursales con Node.js, PostgreSQL y Docker.
- **Sistema AllNet** — Recepción y gestión de equipos de taller con Django + HTMX.
- **TechForge** — Landing page responsive con React y Tailwind CSS.

## ✨ Características

- Diseño responsive (mobile-first)
- Animaciones retro (CRT fade-in, cursor parpadeante)
- Carrusel de imágenes en proyectos y lightbox
- Placeholders con estética terminal para proyectos sin capturas
- Stack técnico agrupado y resumen profesional actualizado desde el CV
- Sección de currículum con vista previa, apertura y descarga del PDF
- Enlaces directos de contacto: email, WhatsApp, LinkedIn y GitHub
